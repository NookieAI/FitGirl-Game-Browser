# FitGirl Game Browser

[![Downloads](https://img.shields.io/github/downloads/NookieAI/FitGirl-Game-Browser/total?style=flat-square&color=8b2fa8)](https://github.com/NookieAI/FitGirl-Game-Browser/releases/latest)

Desktop app for browsing FitGirl Repacks. Encrypted catalog, auto-updates, cross-platform.

## Features

- AES-256-GCM encrypted catalog (decrypted in-memory only, never cached to disk)
- Genre filter, full-text search, sort by title/date/size
- Game detail modal: screenshots, download links, magnet links
- Shows original vs repack size
- Auto-updater with SHA-256 verification
- Single-instance enforcement
- Windows, macOS (ARM + Intel), Linux
